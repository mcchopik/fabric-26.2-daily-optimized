# Fabric 26.2 Daily Optimized

Приватная клиентская сборка для Minecraft 26.2 на Fabric. Она объединяет
оптимизационную основу и уникальные моды из повседневной сборки без повторяющихся
`mod id` и заведомо несовместимой пары Modernica/ModernFix.

## Что внутри

- 82 мода: производительность, интерфейс, графика и повседневные функции.
- Основа оптимизации: Sodium, Lithium, C2ME, FerriteCore, ImmediatelyFast,
  EntityCulling, MoreCulling, Dynamic FPS, Modernica, Threadium и ZakoOpt.
- Визуальная часть: Iris, BetterGrassify, Entity Model/Texture Features,
  LambDynamicLights, 3D Skin Layers, Smart Particles и ScalableLux.
- Интерфейс и удобство: AppleSkin, Better Mount HUD, Chat Heads, WTHIT,
  Zoomify, Chest Tracker, Mod Menu и другие моды исходной повседневной сборки.

## Установка

1. Установить Minecraft 26.2, Fabric Loader 0.19.3 или новее и Java 25.
2. Сделать резервную копию текущей папки `mods`.
3. Удалить старые моды из игровой папки, чтобы не осталось дублей.
4. Скопировать каталог `mods` из релизного архива в каталог игры.
5. Запустить игру. Конфигурации создадутся при первом запуске.

Сборка клиентская. Не копируйте весь набор на сервер.

## Важные замечания

- C2ME и Threadium имеют beta-версии. При проблемах с миром сначала проверяйте
  запуск без Threadium, затем без C2ME.
- Freecam, Fullbright и Local Pack Bypass могут быть запрещены правилами
  отдельных серверов. Используйте их только там, где это разрешено.
- Исходные архивы не содержали конфигураций, ресурспаков или шейдерпаков.
  Перенесены только моды.
- Полный запуск Minecraft в автоматической проверке не выполняется: для него
  нужны клиент, игровые ресурсы и профиль. Целостность JAR, уникальность `mod id`
  и известный конфликт Modernica/ModernFix проверяются автоматически.

Подробности объединения находятся в [MERGE-NOTES.md](MERGE-NOTES.md), результаты
анализа аккаунта GitHub — в [GITHUB-AUDIT.md](GITHUB-AUDIT.md).

## Проверка

```bash
node scripts/validate-mods.mjs
sha256sum -c CHECKSUMS.sha256
```

Все моды принадлежат их авторам и распространяются на условиях лицензий,
вложенных в соответствующие JAR или опубликованных на страницах проектов.
